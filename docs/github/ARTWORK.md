# Banner artwork

The right panel uses Sega's original *Gunblade NY* North American promotional flyer, archived as [Gunblade NY arcade artwork](https://gamesdb.launchbox-app.com/games/images/14480-gunblade-ny) by LaunchBox. Original game artwork and trademarks belong to Sega.

The left panel follows the VR4ALL dark-grid title layout. The flyer is archival artwork, not a screenshot of VR gameplay. No AI-generated game characters or scenes were added.
