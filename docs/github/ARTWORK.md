# Banner artwork

The right panel uses a crop of Sega's original *Gunblade NY* promotional flyer, archived as [Gunblade NY arcade artwork](https://gamesdb.launchbox-app.com/games/images/132056-gunblade-ny) by LaunchBox. Original game artwork and trademarks belong to Sega.

The left panel follows the existing VR4ALL dark-grid title layout. The flyer is archival artwork, not a screenshot of VR gameplay. No AI-generated game characters or scenes were added.
